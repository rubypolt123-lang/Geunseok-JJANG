# chart_analyzer — 차트 캡처 → 분석 보고서

차트를 **캡처하면 바로** Claude 가 이미지를 읽고 기술적 분석 보고서를 만들어 브라우저로 띄워 줍니다.
트레이딩뷰, 바이낸스, 증권사 HTS 등 화면에 보이는 차트면 무엇이든 됩니다.

> **⚠️** 보고서는 AI 가 이미지 한 장만 보고 만든 참고 자료입니다. 투자 조언이 아니며, 가격 판독에 오차가 있을 수 있습니다.

## 무엇을 해 주나요

1. `watch` 를 켜 두고 **Win+Shift+S** 로 차트 영역을 캡처합니다.
2. 클립보드에 새 이미지가 들어오면 자동으로 Claude API 에 보내 분석합니다(보통 30초~2분).
3. `chart_reports/` 폴더에 보고서를 저장하고 브라우저로 엽니다.

보고서 구성:

| 항목 | 내용 |
|---|---|
| 핵심 요약 | 3줄 요약, 종합 판단(강한 상승 ~ 강한 하락), 확신도 |
| 추세 | 단기·중기 방향과 근거, 고점/저점 구조 |
| 주요 가격대 | 지지·저항 가격, 강도, 근거 |
| 패턴 | 차트·캔들 패턴과 완성 조건 |
| 보조지표 · 거래량 | **화면에 보이는** 지표만 판독(없는 지표는 지어내지 않음) |
| 시나리오 | 상승/하락/횡보별 진입 조건, 목표가, 무효화 조건 |
| 리스크 · 체크포인트 | 주의할 위험, 다음 봉에서 확인할 것 |
| 판독 한계 | 이미지에서 읽기 어려웠던 부분 |

저장되는 파일 (이름 예: `20261002-143015_BTCUSDT_4시간.*`):

- `.html` — 캡처 이미지가 들어 있는 보고서 한 장짜리 파일 (브라우저에서 Ctrl+P 로 PDF 저장 가능)
- `.md` — 노션·블로그에 붙여 넣기 좋은 마크다운
- `.png` — 분석한 캡처 원본
- `.json` — 분석 원본 데이터
- `index.html` — 지금까지 만든 보고서 목록(최신순)

## 설치

프로젝트 폴더에서 PowerShell 을 열고 실행합니다. (가상환경은 상위 [README](../README.md#2-요구-사항과-설치) 와 같은 `.venv` 를 써도 됩니다.)

```powershell
$py = ".\.venv\Scripts\python.exe"
& $py -m pip install --only-binary ":all:" -r chart_analyzer\requirements.txt
```

### API 키

Claude API 키가 필요합니다. [platform.claude.com](https://platform.claude.com) 에서 발급한 뒤, 프로젝트 폴더의 `.env` 에 넣습니다.

```
ANTHROPIC_API_KEY=sk-ant-...
```

`.env` 는 git 에 올라가지 않습니다(.gitignore 포함).

## 사용법

명령은 **프로젝트 폴더(이 `chart_analyzer` 폴더가 있는 곳)** 에서 실행합니다. 한글이 깨지면 먼저 `$env:PYTHONUTF8 = "1"`.

### 1) 캡처 감시 모드 — 캡처하면 바로 분석 (추천)

```powershell
& $py -m chart_analyzer watch
```

창을 켜 둔 채로 **Win+Shift+S** → 차트 영역 드래그. 끝내려면 Ctrl+C.

- 감시를 시작할 때 클립보드에 이미 있던 이미지는 분석하지 않습니다.
- 같은 이미지는 두 번 분석하지 않습니다.
- 분석 중(30초~2분)에 여러 장을 연달아 캡처하면 클립보드에는 마지막 것만 남으므로, 한 장씩 결과를 보고 다음 캡처를 하세요.

**스크린샷 폴더도 감시**하려면 (Win+PrtSc 나 캡처 도구 자동 저장을 쓰는 경우):

```powershell
& $py -m chart_analyzer watch --folder "$env:USERPROFILE\Pictures\Screenshots"
# 클립보드는 빼고 폴더만: --no-clipboard 추가
```

### 2) 지금 클립보드에 있는 이미지 한 장만 분석

```powershell
& $py -m chart_analyzer clip
```

### 3) 저장해 둔 이미지 파일 분석

```powershell
& $py -m chart_analyzer file .\캡처1.png .\캡처2.jpg
```

### 공통 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--note "메모"` | 없음 | 분석에 참고할 맥락. 예: `--note "BTC 4시간봉, 롱 진입 고민 중"` |
| `--effort` | `high` | 분석 깊이 `low` / `medium` / `high` / `xhigh` / `max`. 높을수록 꼼꼼하지만 느리고 비쌉니다 |
| `--model` | `claude-opus-5-5` | `claude-sonnet-5-5`(더 빠르고 저렴), `claude-fable-5-1`(가장 강력, 비쌈) |
| `--out 폴더` | `chart_reports` | 보고서 저장 폴더 |
| `--no-open` | 끔 | 보고서를 브라우저로 자동으로 열지 않음 |

`watch` 전용: `--folder 폴더`(여러 번 지정 가능), `--no-clipboard`, `--interval 초`(확인 주기, 기본 1).

## 잘 분석되게 캡처하는 요령

- **가격축(오른쪽 숫자)과 시간축이 보이게** 캡처하세요. 가격 판독은 가격축 눈금을 기준으로 합니다.
- 종목명과 봉 간격(예: `BTCUSDT · 4h`)이 보이는 상단 영역도 포함하면 보고서에 자동으로 들어갑니다.
- 보조지표(RSI, MACD, 이동평균 등)는 화면에 켜 둔 것만 분석합니다. 지표 값 라벨이 보이면 더 정확합니다.
- 너무 많은 봉을 압축해서 보이기보다, 판단하려는 구간이 잘 보이게 확대해서 캡처하세요.
- 4K 화면 캡처도 괜찮습니다. 긴 변 2576px 로 자동 축소해서 보냅니다.

## 비용

이미지 한 장 분석이 API 요청 1번입니다. Claude Opus 5.5, `--effort high` 기준으로 대략 한 장에 0.1~0.2달러 안팎이며, 실제 사용량은 보고서 하단의 토큰 수와 Claude 콘솔에서 확인할 수 있습니다. 비용을 줄이려면 `--effort medium` 이나 `--model claude-sonnet-5-5` 를 쓰세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `API 키가 없거나 잘못되었습니다` | `.env` 에 `ANTHROPIC_API_KEY` 가 있는지, 프로젝트 폴더에서 실행했는지 확인 |
| `클립보드에 이미지가 없습니다` | Win+Shift+S 로 캡처했는지 확인. 이미지 파일은 탐색기에서 복사(Ctrl+C)해도 됩니다 |
| 캡처해도 반응이 없음 | 감시 시작 전에 이미 있던 이미지와 같은 이미지인지 확인. 새로 캡처해 보세요 |
| `응답이 길이 제한에 걸려 잘렸습니다` | `--effort` 를 한 단계 낮춰 다시 시도 |
| 한글이 깨짐 | `$env:PYTHONUTF8 = "1"` 후 다시 실행 |
