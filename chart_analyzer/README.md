# 차트 분석기 — 캡처하면 바로 분석 보고서

차트 화면을 **캡처하면 바로** AI(Claude)가 그림을 읽고 분석 보고서를 만들어 인터넷 창으로 띄워 줍니다.
트레이딩뷰, 바이낸스, 증권사 HTS 등 화면에 보이는 차트면 무엇이든 됩니다.

> **⚠️** 보고서는 AI 가 그림 한 장만 보고 만든 참고 자료입니다. 투자 조언이 아니며, 가격을 읽을 때 오차가 있을 수 있습니다.

---

## 처음 사용하는 분은 이것만 따라 하세요

명령어를 칠 필요 없이 **더블클릭**만 하면 됩니다.

### 1단계. 파이썬 설치 (이미 있으면 건너뛰기)

1. <https://www.python.org/downloads/> 에서 **Download Python** 버튼을 눌러 받습니다.
2. 받은 파일을 실행하고, 첫 화면 아래쪽 **"Add python.exe to PATH"** 를 꼭 체크한 뒤 **Install Now** 를 누릅니다.

### 2단계. 설치 파일 더블클릭

프로젝트 폴더에 있는 **`차트분석기_설치.bat`** 을 더블클릭합니다.

- 까만 창이 뜨고 필요한 것들을 알아서 설치합니다 (몇 분 걸려요).
- 끝나면 **바탕화면에 `차트 분석기` 아이콘**이 생기고, 분석기 창이 바로 열립니다.
- "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** 을 누르세요.

### 3단계. API 키 넣기 (처음 한 번만)

분석기 창이 처음 열리면 **API 키 설정** 창이 뜹니다.

1. **[Claude 콘솔 열기]** 를 눌러 로그인합니다 (계정이 없으면 가입).
2. 콘솔의 **Billing** 에서 크레딧을 충전합니다 (분석 1장에 대략 0.1~0.2달러).
3. **API Keys → Create Key** 로 키를 만들고, `sk-ant-` 로 시작하는 키를 복사합니다.
4. 분석기의 칸에 붙여 넣고(Ctrl+V) **[저장]** — 키가 맞는지 자동으로 확인한 뒤 저장합니다.

### 4단계. 차트 캡처하기

1. 분석기 창을 켜 둔 채로 차트 화면으로 갑니다. (창 맨 위가 초록색 **"자동 분석 켜짐"** 이면 준비 완료)
2. **Win + Shift + S** 를 누르고, 분석할 차트 부분을 마우스로 드래그합니다.
3. 30초~2분 뒤 분석 보고서가 인터넷 창으로 열립니다. 끝!

다음부터는 바탕화면의 **`차트 분석기`** 아이콘만 더블클릭하면 됩니다.
(아이콘이 없으면 프로젝트 폴더의 `차트분석기_실행.bat` 을 더블클릭하세요.)

## 분석기 창 둘러보기

| 화면 부분 | 하는 일 |
|---|---|
| 맨 위 색깔 띠 | 지금 상태. 초록 = 캡처 기다리는 중, 파랑 = 분석 중, 회색 = 자동 분석 꺼짐, 주황 = API 키 필요 |
| **자동 분석 켜기/끄기** | 끄면 캡처해도 분석하지 않습니다 (다른 캡처 작업을 할 때) |
| **클립보드 이미지 분석** | 방금 복사한 그림을 직접 분석시킵니다 |
| **이미지 파일 선택...** | 저장해 둔 차트 사진(png, jpg 등)을 골라 분석합니다. 여러 장 선택 가능 |
| 메모 | 상황을 적으면 참고해서 분석합니다. 예) `롱 진입 고민 중`, `4시간봉 기준` |
| 분석 깊이 | **빠르게**(저렴) / **보통**(추천) / **꼼꼼하게**(느리고 비쌈) |
| 최근 보고서 | 지난 보고서 목록. **더블클릭하면 열립니다** |
| 보고서 폴더 열기 / 전체 목록 | 저장된 보고서 파일을 봅니다 |
| API 키 설정 / 사용 방법 | 키를 바꾸거나, 사용법을 다시 봅니다 |
| 진행 기록 | 무엇을 하고 있는지, 결과 요약, 실패 이유가 나옵니다 |

분석하는 동안 여러 장을 캡처해도 됩니다. 순서대로 하나씩 분석합니다.

## 보고서에는 이런 내용이 들어갑니다

| 항목 | 내용 |
|---|---|
| 핵심 요약 | 3줄 요약, 종합 판단(강한 상승 ~ 강한 하락), 확신도 |
| 추세 | 단기·중기 방향과 근거, 고점/저점 구조 |
| 주요 가격대 | 지지·저항 가격, 강도, 근거 |
| 패턴 | 차트·캔들 패턴과 완성 조건 |
| 보조지표 · 거래량 | **화면에 보이는** 지표만 판독 (없는 지표는 지어내지 않음) |
| 시나리오 | 상승/하락/횡보별 진입 조건, 목표가, 틀렸다고 볼 가격 |
| 리스크 · 체크포인트 | 주의할 위험, 다음 봉에서 확인할 것 |
| 판독 한계 | 그림에서 읽기 어려웠던 부분 |

보고서는 프로젝트 폴더의 `chart_reports` 폴더에 쌓입니다 (이름 예: `20261002-143015_BTCUSDT_4시간`).

- `.html` — 보고서 (인터넷 창에서 **Ctrl+P → PDF로 저장** 가능)
- `.md` — 노션·블로그에 붙여 넣기 좋은 글
- `.png` — 분석한 캡처 그림
- `.json` — 분석 원본 데이터
- `index.html` — 지금까지 만든 보고서 목록

## 잘 분석되게 캡처하는 요령

- **오른쪽 가격 숫자(가격축)** 가 보이게 캡처하세요. 가격은 가격축 눈금을 보고 읽습니다.
- 위쪽의 **종목 이름과 봉 간격**(예: `BTCUSDT · 4h`)도 같이 캡처하면 보고서에 자동으로 들어갑니다.
- RSI, MACD 같은 보조지표는 **화면에 켜 둔 것만** 분석합니다. 지표 값 숫자가 보이면 더 정확해요.
- 너무 많은 봉을 작게 담기보다, 판단하고 싶은 구간이 잘 보이게 확대해서 캡처하세요.
- 4K 화면 캡처도 괜찮습니다. 알맞은 크기로 줄여서 보냅니다.

## 비용

캡처 1장 = 분석 요청 1번입니다. 기본 설정(보통)으로 **한 장에 대략 0.1~0.2달러** 정도이며, 정확한 사용량은 각 보고서 맨 아래(토큰 수)와 Claude 콘솔에서 볼 수 있습니다. 아끼려면 분석 깊이를 **빠르게** 로 고르세요.

## 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| 설치 창에 "파이썬이 설치되어 있지 않습니다" | 1단계대로 파이썬을 설치하고 **"Add python.exe to PATH"** 를 체크했는지 확인 |
| 설치 창에 "창 화면 기능(tcl/tk)이 빠져 있습니다" | 윈도우 설정 → 앱 → Python → 수정 → Modify → **tcl/tk and IDLE** 체크 |
| 바탕화면 아이콘을 눌러도 아무것도 안 뜸 | `차트분석기_실행.bat` 을 더블클릭해 안내를 확인. 안 되면 `차트분석기_설치.bat` 을 다시 실행 |
| 맨 위가 주황색 "API 키를 먼저 설정해 주세요" | **API 키 설정** 버튼을 눌러 키를 넣으세요 |
| "API 키가 올바르지 않습니다" | 키를 끝까지 다 복사했는지 확인하고 다시 붙여 넣으세요 |
| "API 크레딧이 부족합니다" | Claude 콘솔 → Billing 에서 충전 |
| 캡처해도 반응이 없음 | 맨 위가 초록색(자동 분석 켜짐)인지 확인. 꺼져 있으면 **자동 분석 켜기** |
| 분석기가 열리다가 오류 창이 뜸 | `chart_reports\오류기록.txt` 내용을 캡처해서 물어봐 주세요 |

## 고급: 명령어로 쓰기

창 없이 PowerShell 에서 쓸 수도 있습니다. 프로젝트 폴더에서 실행하세요 (한글이 깨지면 먼저 `$env:PYTHONUTF8 = "1"`).

```powershell
$py = ".\.venv\Scripts\python.exe"
& $py -m chart_analyzer                # 분석기 창 열기 (gui 와 같음)
& $py -m chart_analyzer watch          # 콘솔에서 캡처 감시
& $py -m chart_analyzer clip           # 지금 클립보드 그림 한 장 분석
& $py -m chart_analyzer file a.png b.jpg
& $py -m chart_analyzer shortcut       # 바탕화면 바로가기 다시 만들기
```

| 옵션 (watch / clip / file) | 기본값 | 설명 |
|---|---|---|
| `--note "메모"` | 없음 | 분석에 참고할 상황 설명 |
| `--effort` | `high` | `low` / `medium` / `high` / `xhigh` / `max` |
| `--model` | `claude-opus-5-5` | `claude-sonnet-5-5`(빠르고 저렴), `claude-fable-5-1`(가장 강력, 비쌈) |
| `--out 폴더` | `chart_reports` | 보고서 저장 폴더 |
| `--no-open` | 끔 | 보고서를 자동으로 열지 않음 |

`watch` 전용: `--folder 폴더` (새로 저장되는 이미지 파일도 감시, 예: `"$env:USERPROFILE\Pictures\Screenshots"`), `--no-clipboard`, `--interval 초`.

API 키는 프로젝트 폴더의 `.env` 파일에 `ANTHROPIC_API_KEY=sk-ant-...` 로 저장됩니다 (분석기 창에서 설정하면 자동으로 들어감). `.env` 는 git 에 올라가지 않습니다.

### 테스트

API 를 호출하지 않는 단위 테스트입니다. 창 테스트는 화면이 없는 환경에서는 건너뜁니다.

```powershell
& $py -m pip install pytest
& $py -m pytest chart_analyzer
```
