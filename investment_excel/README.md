# 투자관리 엑셀 — 바이낸스 · 주식 (무료)

바이낸스 코인과 국내·해외 주식을 **엑셀 파일 하나**로 관리합니다.
거래만 적으면 보유현황·손익·수익률이 자동으로 계산되고, 종목마다 **전문적인 일봉 캔들차트**(이동평균선·거래량 포함)가 그려집니다.
시세는 **무료 공개 데이터**로 받습니다. API 키도 회원가입도 필요 없습니다.

> **⚠️** 무료 공개 시세라 늦거나 일부 빠질 수 있습니다. 투자 판단의 책임은 본인에게 있습니다.

---

## 처음 사용하는 분은 이것만 따라 하세요

1. **파이썬 설치** (이미 있으면 건너뛰기): <https://www.python.org/downloads/> 에서 받아 설치합니다. 첫 화면의 **"Add python.exe to PATH"** 를 꼭 체크하세요.
2. 프로젝트 폴더의 **`투자관리_시세업데이트.bat`** 을 더블클릭합니다.
   - 처음에는 필요한 것을 알아서 설치하고, **`투자관리.xlsx`** 를 새로 만든 뒤 엑셀로 엽니다.
   - 처음 파일에는 예시 종목(비트코인, 이더리움, 삼성전자, 애플)과 예시 거래가 들어 있습니다. 지우고 내 것으로 바꾸세요.
3. 엑셀에서 **노란 칸**만 채웁니다.
   - **[종목]** 시트: 가지고 있거나 관심 있는 종목
   - **[거래기록]** 시트: 매수·매도할 때마다 한 줄
4. 시세를 새로 받고 싶을 때마다 **엑셀을 닫고** `투자관리_시세업데이트.bat` 을 다시 더블클릭합니다.

## 종목코드 적는 법

| 시장 | 종목코드 예 | 시세 출처 (무료) |
|---|---|---|
| 바이낸스 | `BTCUSDT`, `ETHUSDT`, `SOLUSDT` (바이낸스 심볼 그대로) | 바이낸스 공개 API (현물, 없으면 USDT-M 선물) |
| 국내주식 | `005930` 삼성전자, `000660` SK하이닉스 (6자리) | 네이버 금융 |
| 해외주식 | `AAPL`, `TSLA`, `NVDA`, `7203.T` (야후 파이낸스 기호) | 야후 파이낸스 |
| 기타 | 금, 예금, 비상장 등 | 자동 시세 없음 → [종목]의 **수동 현재가** 칸에 직접 입력 |

환율(USD/KRW)도 야후 파이낸스에서 자동으로 받습니다 ([설정]에서 끌 수 있음). USDT 는 1달러로 계산합니다.

## 시트 안내

| 시트 | 내용 |
|---|---|
| **대시보드** | 총 평가금액·보유원가·평가손익·수익률·실현손익(원화), 시장별 비중 원그래프, 시장별 평가금액 비교 차트 |
| **일봉차트** | 종목마다 최근 120일 **캔들차트**(상승 빨강 / 하락 파랑) + **20일·60일 이동평균선** + **거래량**. 위쪽 링크를 누르면 그 종목으로 이동 |
| **보유현황** | 종목별 보유수량, 평균단가, 현재가, 평가금액, 평가손익, 수익률, 실현손익, 원화 환산, 비중 |
| **거래기록** ✏️ | 날짜·종목코드·구분(매수/매도)·수량·단가·수수료 입력 (종목코드·구분은 목록에서 선택) |
| **종목** ✏️ | 종목코드·이름·시장·통화·수동 현재가 |
| **설정** ✏️ | USD/KRW 환율, 환율 자동 업데이트 여부 |
| **일봉데이터** | 시세 업데이트가 채우는 일봉 (자동 시세가 없는 종목은 같은 형식으로 직접 입력 가능) |

손익은 국내 관례대로 **이익 빨강 / 손실 파랑** 으로 표시합니다.

## 계산 방식

- **평균단가** = (매수금액 합계 + 매수 수수료) ÷ 매수수량 합계
- **실현손익** = 매도금액 − 매도 수수료 − 매도수량 × 평균단가
- **현재가** = [종목]의 수동 현재가가 있으면 그 값, 없으면 일봉데이터의 마지막 종가
- 수수료는 그 종목 가격과 같은 통화로 적습니다 (바이낸스는 USDT).

## 업데이트할 때 알아 둘 점

- 업데이트는 **노란 칸의 입력값(종목·거래기록·설정)과 일봉데이터를 그대로 옮겨 담아 파일을 새로 만듭니다.** 그래야 차트 축이 가격에 맞게 다시 그려집니다. 노란 칸 밖에 직접 넣은 내용(서식, 추가한 시트 등)은 유지되지 않습니다.
- 업데이트 전 파일은 **`투자관리_백업`** 폴더에 자동으로 보관됩니다 (최근 20개).
- 시세를 못 받은 종목은 이전 데이터를 그대로 둡니다. 이유는 까만 창에 표시됩니다.
- 엑셀에서 파일이 열려 있으면 저장이 안 됩니다. 닫고 다시 실행하세요.
- `투자관리.xlsx` 와 백업은 개인 거래기록이라 git 에 올라가지 않습니다 (.gitignore).

## 무료로 여는 방법

마이크로소프트 엑셀, **무료 엑셀 웹(office.com)**, **리브레오피스 캘크(무료)** 에서 열 수 있습니다.
특별한 함수(최신 엑셀 전용)나 매크로를 쓰지 않습니다.

## 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| "파이썬이 설치되어 있지 않습니다" | 위 1번대로 설치하고 **Add python.exe to PATH** 체크 |
| "저장하지 못했습니다 … 닫고 다시 실행하세요" | 엑셀에서 `투자관리.xlsx` 를 닫고 다시 실행 |
| 어떤 종목만 "✖ … 시세를 받지 못했습니다" | 종목코드·시장을 확인 (국내 6자리, 바이낸스 `…USDT`, 해외는 야후 기호) |
| 보유현황 현재가가 0 | 그 종목의 일봉데이터가 없습니다. 업데이트를 하거나 수동 현재가 입력 |
| 차트가 안 보임 | 일봉데이터가 있는 종목만 차트가 생깁니다. 업데이트를 실행하세요 |
| 파일이 망가진 것 같음 | `투자관리_백업` 폴더의 최근 파일을 `투자관리.xlsx` 로 복사 |

## 고급: 명령어

```powershell
$py = ".\.venv\Scripts\python.exe"
& $py -m investment_excel                  # 만들기 / 시세 업데이트
& $py -m investment_excel D:\내투자.xlsx    # 다른 위치의 파일
& $py -m investment_excel --offline        # 인터넷 없이 (새 파일은 예시 데이터)
& $py -m pytest investment_excel           # 테스트 (인터넷 안 씀)
```
